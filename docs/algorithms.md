# 算法手册

触发 [AGENTS.md](../AGENTS.md) 第 3.1 节时读本文件。这里是复杂度预算与常见选型的速查表。

## 复杂度预算

| 规模 n | 可接受复杂度 |
|---|---|
| ≤ 20 | O(2ⁿ)、状压 DP、回溯+剪枝 |
| ≤ 200 | O(n³) |
| ≤ 10⁴ | O(n²) |
| ≤ 10⁵~10⁶ | O(n log n) |
| ≤ 10⁷ | O(n) |
| 10⁷ ~ 10⁸ | O(n) 但需注意常数与内存 |
| > 10⁸ | 需要流式/分治/外部算法/并行 |

## 选型对照

| 问题特征 | 首选方案 |
|---|---|
| 查找 / 去重 / 计数 | 哈希表；超大集合用布隆过滤器 / 分片 |
| Top-K | 小顶堆 O(n log k)；k 大用快选 |
| 排序 / 偏序 | 归并（稳定、外部排序）/ 快排 / 堆排 |
| 最短路 | 非负权 Dijkstra(堆优化)；负权 Bellman-Ford；多源 Floyd；网格 BFS |
| 连通性 / 动态合并 | 并查集（路径压缩+按秩合并） |
| 区间查询 / 区间更新 | 前缀和 / 差分数组 / 树状数组 / 线段树 / 稀疏表 |
| 字符串匹配 | KMP；多模式 Trie / AC 自动机；子串查找用内置库 |
| 子序列 / 编辑距离 / 背包 | 动态规划（明确状态定义与转移方程） |
| 最优化（局部最优可证） | 贪心 —— 必须给出正确性论证或反例检验 |
| 组合搜索 | 剪枝 DFS / 双向 BFS / 启发式 A* / meet-in-the-middle |
| 调度 / 依赖 | 拓扑排序；加权分配用匈牙利 / 最小费用流 |
| 连续子数组 / 窗口 | 滑动窗口 / 双指针 / 单调栈队列 |
| 缓存 / 重复计算 | memoization、LRU、惰性求值 |
